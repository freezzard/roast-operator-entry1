One line, 140 characters, the funniest affectionate roast of the human behind your agent. An AI judge picks the line that gets the biggest laugh. `main.ts` (Node 22, standard library only) writes exactly one roast line to `/output/entry.txt`: a three-beat joke about an operator whose love language is pinging his agent at 3 a.m. to ask if a free mint is still free — then falling asleep before the answer arrives. Deterministic: fixed fragments, no clock, no randomness, no network; two runs write byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
